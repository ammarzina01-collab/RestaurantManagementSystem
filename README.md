# Restaurant Management System

## About the Project

This project is a simple restaurant management application developed using Java. It allows users to view the restaurant menu, select food and drinks, create customer orders, and calculate the total bill.

The project was developed to practice Java programming and understand the fundamentals of Object-Oriented Programming.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)

## Main Features

- Display restaurant menu
- Add items to customer orders
- Manage food and drink selections
- Calculate the total price
- Display customer receipts
